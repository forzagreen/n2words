How the codes work

Codes are IETF BCP 47. A language is the primary subtag — English is one language with 16 regional variants, not 16 languages. Most languages also have a bare-tag entry point (n2words/de) that resolves to one documented default variant; the few whose variants genuinely diverge in script or core numbering grammar — Chinese, Portuguese, Serbian, Amharic — stay region- or script-qualified.

toCurrency is the one form a bare tag won't guess at: a bare tag names a language, and a default currency belongs to a country. Import the region-qualified code for its default, or pass an explicit { currency }.

Full detail lives in LANGUAGES.md and docs/bare-tag-aliases.md.
